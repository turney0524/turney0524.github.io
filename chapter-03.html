3.1

CONCEPT / DERIVATION / EXPLORATION

Hilbert 空间

函数也可以是向量，坐标却不必只有三个。

在普通几何中，向量可以相加、乘以标量。波函数也有这些运算。量子态所处的自然空间是平方可积函数构成的 Hilbert 空间：函数的模平方积分有限，内积给出两态之间的重叠。归一化的态是这个空间中的单位向量。

读这个式子：内积对第二个变量线性，对第一个变量共轭线性。交换次序时要复共轭。

所有平方可积函数构成向量空间；所有“已经归一化为 1”的函数则不构成向量空间，因为相加后不一定仍为单位长度。Cauchy–Schwarz 不等式 |⟨f|g⟩|²≤⟨f|f⟩⟨g|g⟩，以后会成为不确定关系的关键。

一步一步算

把连续函数的想法缩成二维

取 |ψ⟩=cos(θ/2)|0⟩+eⁱᵠsin(θ/2)|1⟩。它有两个复系数，模平方之和为 1。相对相位 φ 不改变 z 基的概率，却会改变别的基中的概率。

精确自旋 1/2 概率。球内箭头为 Bloch 向量，灰色箭头为测量轴；β 轴取在 x–z 平面。

3.2

CONCEPT / DERIVATION / EXPLORATION

可观测量与定值态

一次测量允许的数值，由算符的谱决定。

可观测量由自伴算符表示；在有限维中就是满足 Q†=Q 的厄密矩阵。自伴性保证谱为实数，并支持谱分解。无穷维中必须同时交代定义域和边界条件，形式上积分分部“看起来对称”并不足以自动证明自伴。

读这个式子：方差为零意味着 (Q̂−⟨Q⟩)|ψ⟩=0，故定值态正是相应算符的本征态。

不同本征值对应的本征态正交；同一本征值若有多个独立本征态，叫简并。在简并子空间中可以挑选正交归一基，但测量某一本征值并不会自动分辨该子空间里的不同方向。

位置算符和动量算符可否只靠公式就判断性质？
不可以。−iℏd/dx 是微分表达式；其定义区间与边界条件也是算符的一部分。例如环上的周期边界与有限区间的其他边界，会改变动量谱和自伴性问题。
3.3–4

CONCEPT / DERIVATION / EXPLORATION

分立谱、连续谱与广义统计诠释

投影的模平方，把所有测量统一起来。

对于离散谱，将态展开为 |ψ⟩=Σcₙ|qₙ⟩，测得 qₙ 的概率为 |cₙ|²。对于连续谱，求和变积分，系数的模平方成为概率密度。本征函数以 δ 归一化，而不是普通的单位归一化。

读这个式子：Πq 是该本征值整个本征子空间的投影。非简并时才等于单一 |q⟩⟨q|。

理想投影测量得到 q 后，状态更新为 Πq|ψ⟩/√P(q)。这解释了立即重复测同一个量的结果可重复，也解释了插入一个不对易测量会改变后面的统计。

3.5

CONCEPT / DERIVATION / EXPLORATION

不确定关系

对易子给出下限，协方差解释更细的结构。

读这个式子：由对中心化算符作用后的两个态使用 Cauchy–Schwarz 不等式导出；状态须属于所需算符与乘积的定义域。

对 [x̂,p̂]=iℏ，得到 σₓσₚ≥ℏ/2。两个算符不对易，不意味着在每个态中这个下限都严格大于零；还要计算对易子的期待值。最小位置—动量乘积要求相应的中心化波函数线性相关，且额外协方差为零。

读这个式子：二次相位 c 不改变位置密度，却扩大动量宽度。这里 c 的单位为长度的倒数平方。

3.6

CONCEPT / DERIVATION / EXPLORATION

Dirac 符号

态本身，与它在某组基里的坐标，分开写。

读这个式子：完备关系是“把所有方向的投影加回来”。连续基中用 ∫|x⟩⟨x|dx=I。

ket |ψ⟩ 是抽象态，bra ⟨ψ| 是其共轭线性对偶。内积 ⟨φ|ψ⟩ 是数，外积 |φ⟩⟨ψ| 是算符。一个算符的矩阵元 Qmn=⟨m|Q̂|n⟩，矩阵的具体数值依赖基，但可测预测不依赖你的记号选择。

一步一步算

一次基变换，检查不变的量

如果坐标列向量变为 ψ′=Uψ，其中 U 为酉矩阵，那么算符矩阵也要同时变为 Q′=UQU†。此时 ψ′†Q′ψ′=ψ†Qψ。不只改态的系数，也不只改算符矩阵。

从现在开始的通用流程

先写态和测量算符，找所需的本征基，计算投影，再计算概率与状态更新。不要把所有问题都强行还原为“粒子在哪里”。

RECALL & PRACTICE

合上这一章之前

先用自己的话回答，再展开检查。

|ψ⟩=(|0⟩+i|1⟩)/√2，在 z 基和 x 基的概率？
z 基为 1/2、1/2；x 基也为 1/2、1/2。换成相对相位 0，则 x 基的 + 结果概率为 1，说明相位信息确实可测。
两个可观测量对易时，有什么意义？
在本课程的有限维或适当谱条件下，可以选共同本征基。对于无界算符，严格的共同测量条件还须关注谱投影是否对易。
投影 |q⟩⟨q| 与内积 ⟨q|ψ⟩ 有何不同？
前者是算符，后者是复数。前者作用于 |ψ⟩ 后得到沿 |q⟩ 方向的投影态。
