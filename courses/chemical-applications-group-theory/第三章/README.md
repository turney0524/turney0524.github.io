# 第三章：分子对称性和对称群

打开 `index.html` 阅读。保留奶油白、深海军蓝与金色的课程风格，正文与公式离线可读，16组交互无需安装浏览器插件。完整目录在上一级 `index.html`。

## 内容与课本对应

对照 Cotton 中英文第三版，覆盖3.1–3.15全部小节、九组分类实例及A–E习题。教学正文逐项解释定义、操作矩阵、乘积关系、点群族、多面体、共轭类、手性与构象；原书定义与规则使用引文标记。

逐节可展开中译本书页13–45的原话与原图。习题附中译本42–45、英文本61–67完整原页，保留扫描本题目和示意图。复杂图形题提供分析方法与部分参考解法，并非每一道习题均有完整解答。中英文部分题目和排版存在差异，正文指出可疑印刷表述及相应限制。

`assets/原文对照` 中40张图片是用户提供扫描本的本地对读资料，需与HTML一起保留；此版本已接入网站课本蒸馏栏目。教学正文、几何模型和代码为独立编写。

## 使用方法

- 点击操作按钮，查看分子变换、类型匹配与矩阵；拖动画布改变相机，滚轮缩放。
- 用构象滑块研究氨、过氧化氢、乙烷与二茂铁；精确端点才会增加某些对称操作。
- 对比C4/C4v、T/Td的共轭类，探索多面体与图案如何降低对称性。
- 每个模型下方可展开实际计算代码。反射、反演的中间插值仅作教学示意，终点才用于判断对称性。

## 文件与复现

- `第三章_分子对称性和对称群.md`：完整教学正文。
- `assets/symmetry.js`：三维矩阵、群闭包、共轭类、原子匹配与几何模型。
- `assets/chapter.js`：画布、动画与交互界面。
- `examples.py`：独立NumPy算例。安装NumPy后运行 `python3 examples.py`。
- `source/verify.cjs`：运行 `node source/verify.cjs`，输出数值校验报告。
- `source/build.py`：需要 `markdown2` 与 `latex2mathml`；运行后重建两个HTML。
- `校验报告.json`：保存的数值检查结果；矩阵容差与被测项目见核验脚本。

HTML已内嵌样式、脚本和MathML，不依赖CDN。原页图片及下载文件使用相对路径，移动或打包时请保留整个目录。
