# 群论在化学中的应用：全书动态伴读

打开本目录 `index.html`，即可进入十一章目录。现有第一至三章保留；新增第四至十一章逐节教学伴读、48组交互实验，并接入原书附录与中译本习题解答。全课程共84组交互模块，章节之间有前后导航。

## 本次交付的内容层次

- **完整教材原文**：后续八章及附录的中英文扫描页保存在本地翻页器中，原话、所有页内公式、插图、表格、题目和脚注可连续阅读。支持中英对照、中文单栏放大、英文单栏放大与原尺寸查看。
- **教学伴读**：第四至十一章按原书51个小节独立讲解主要概念、公式推导与实例，增加简单算例、学习检查和模型限制。不是将原书数百页逐字重新排版，也不是全部复杂习题的另编详解。
- **动态计算**：从实际矩阵、投影、对角化、占据和复相位求和计算结果；每个实验下可展开该模型的实际源码，并下载JS与独立NumPy算例。
- **附录与原书解答**：保留两版特征标表、相关表、f轨道图、双群、空间群和参考文献；中译本另有完整原书习题解答。

## 使用与移动

无需浏览器插件或网络服务。公式采用原生MathML，脚本为普通JavaScript。可直接打开本地HTML；移动文件或分享本地副本时，保留整个目录层级，不能只复制一个HTML。压缩包不包含原始PDF，但包含页面显示所需的全部扫描图片。

原书页目录中中文版PDF61–402共342张，英文版PDF77–481共405张，均由用户提供教材渲染，保留原样。中文印刷页通常为PDF页减15，英文减9；英文末尾PDF471–481实际是另附特征标表册1–11页，翻页器为连续查阅将其记作资料序号462–472，并在附录中明确说明。

本课程发布于计算凝聚态物理网站的课本蒸馏栏目。

## 学习路径

先读原书与伴读，暂停实验预测结果，再操作并核对公式；最后做原题、查原书解答。阅读完成勾选只存在本机浏览器。动画中相位颜色与原子电荷无关；示意的反射中间帧、轨道截面、简单晶场和两态模型均有适用范围说明。

- 前端数值核心：`共享资源/numerics.js`。

- 数值校验：`node 课程源码/verify.cjs`，输出JSON；既有第三章另有自己的校验脚本。
