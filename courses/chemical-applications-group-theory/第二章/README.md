# 第二章 · 群论的定义和定理（详细动态伴读）

## 打开

直接用现代浏览器打开 `第二章_群论的定义和定理_动态课本.html`（与 `index.html` 内容一致）。所有样式、MathML公式与JavaScript均已内置；阅读与计算无需联网、CDN或安装插件。相邻章节及源码下载链接需要保留文件夹结构。

## 覆盖范围

逐项核对 Cotton 第三版的中译本书页5–12（PDF20–27）和英文本书页6–16（PDF15–25）。原书位于本目录上两级的“群论”目录。本页覆盖2.1–2.4全体主题与章末2.1–2.10全部习题；定理证明完整展开，原书略过的中心化子计数等另作补充。

12组实验：逆序撤销、整数加法、可编辑群公理检查、三阶表推导、循环时钟、四阶群对比、三角形乘法、子群闭包、陪集分包、共轭三步、类大小/中心化子、完整群浏览器。十五种有限群的全表、全子群、全共轭类同时提供静态附表与JSON。

两版可疑处（习题2.4、2.5，以及中译本两项中间共轭结果）已在正文明确说明。没有为了匹配文字而编造不成立命题的证明。实际乘积均由精确群运算独立核验。

## 文件与重建

- `第二章_群论的定义和定理.md`：完整可编辑正文。
- `第二章_完整笔记与群表.md`：正文加十五种群的全部静态数据，构建时同步生成。
- `assets/groups.js`：精确有限群运算核心，可被浏览器与Node使用。
- `assets/chapter.js`：控件、变换动画、表格、可展开源码。
- `assets/chapter.css`：沿用第一章排版与配色，补充表格和集合着色。
- `assets/full-groups.json`：十五种群的完整数据。
- `examples.py`：纯标准库Python，以置换独立实现S3，验证群表、子群、陪集及共轭类。
- `source/verify.cjs`：全公理、逆元、子群、陪集、类、中心化子、矩阵表示与教材表对照核验。
- `source/export.cjs`：由精确引擎导出JSON供静态附表构建。
- `source/build.py`：生成两份相同的离线HTML。
- `核对资料/`：私人扫描核对中间文件；不属于公开课程资源，发布时排除。

```sh
node source/verify.cjs
python examples.py
python -m pip install markdown2 latex2mathml
python source/build.py
```

构建需要Python、Node及两个Python排版库；成品使用不需要这些依赖。构建器兼容本机已有临时库路径，正常pip安装后也可直接运行。

群表约定固定为：UI行Y列X显示XY，内部数组`table[X][Y]`保存此乘积。抽象运算内部采用通常的左因子、右因子索引，不因表格布局而改变。
