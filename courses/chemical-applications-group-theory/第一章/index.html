01 为什么实验工作也需要理论？

从“看到了什么”走向“为什么这样看”

原章先从实验工作者的处境谈起：化学知识和实验技术都很庞大，一个人很难同时精通所有理论。可是，要有目的地设计实验、把不同观测联系起来，就需要某种理论框架。群论提供的正是一套相对轻便的语言：先利用系统在某些操作下保持不变的事实，约束允许出现的行为。

想象一份谱图。某个预期峰没有出现，可能是信号太弱，也可能是相应跃迁在所采用的近似下被对称性严格禁止。二者会引向不同的实验方案：前者可能需要更高灵敏度，后者可能需要改变偏振、环境或探测机制。对称性分析帮助我们先把问题分类，再决定值得投入什么计算。

这也解释了作者为什么把分子量子力学作为普遍需要的背景。化学键、分子轨道和分子动力学都涉及波函数、能量和相互作用；群论并不替代这些对象，而是把它们按变换方式组织起来。读这一章只需先认得波函数、哈密顿量、本征态和跃迁这几个概念，不必先掌握整套高等数学。

用水分子看清“没变”与“没动”的区别〔教学扩展〕

把水分子的 O 放在原点，分子放在 yz 平面，角平分线沿 z 轴。绕 z 轴转动 180°，两个 H 交换位置，完整分子仍然与原来重合。整体图案不变，不代表每个原子都留在原位。若给两个 H 加上仅供追踪的编号，编号会交换；编号本身不改变分子的物理性质。

如果一个 H 真正换成 D，同位素身份就成为系统的一部分。理想平衡核位置仍可呈现相同几何轮廓，但核质量分布不再在该交换下不变；尤其振动问题必须把质量考虑进去。几何对称性、电子问题中固定核电荷的对称性和完整核运动哈密顿量的对称性，应按讨论对象区分。

动手做： 点击 C₂(z)，先追踪 H₁，再取消编号，看最终点集是否重合；切到 HDO 后再比较。动画中的连续转动是观察操作的路径，中途不要求是水分子的对称操作。

02 对称性给约束，动力学给数值

原章的核心分界

原章接下来强调：利用对称性可以在不求出所有数值细节之前，判断状态应怎样分类、哪些相互作用和跃迁可能存在。可是，允许发生不等于一定发生；允许的过程有多强、能级相隔多远、谱峰出现在哪里，还要依赖哈密顿量参数、计算或测量。

这里还要把原章的概括放到准确的适用范围内理解。对称性并不能凭空告诉我们完整系统一共有多少能态。先给定轨道基、振动自由度或所研究的希尔伯特空间，才能讨论它们怎样分成不同对称类型。对称性可强制某些简并，也可阻止某些耦合；属于不同类型的能级仍可能偶然等能，不能把“类型不同”自动读成“能量必定不同”。

从不变性到对易关系〔教学扩展〕

用幺正算符 U(g) 表示一次对称操作。若它不改变哈密顿量，则

U(g)HU(g)−1=H.

右乘 U(g)，得到 U(g)H=HU(g)，即

[H,U(g)]=0.

假设 H|ψ⟩=E|ψ⟩，那么

HU(g)|ψ⟩=U(g)H|ψ⟩=EU(g)|ψ⟩.

因此，对称操作把一个能量 E 的态送到同一能量的本征子空间。它可能只乘上一个相位，也可能在一组简并态中作线性组合。这个结论解释了“为什么对称性能够组织能态”；不可约表示和简并之间更系统的关系将在后续章节建立。

一个能亲手算完的双轨道模型〔教学扩展〕

取两条正交、归一化的局域轨道 |L⟩、|R⟩，用 P 交换它们。忽略自旋，采用实参数：

P=(0110),H=(ε+δttε−δ).

ε 是平均现场能；t 是两轨道耦合；δ 是左右环境的不等价程度。矩阵相乘得到

[H,P]=(02δ−2δ0).

当 δ=0 时，对称和反对称组合为

|+⟩=|L⟩+|R⟩2,|−⟩=|L⟩−|R⟩2,P|±⟩=±|±⟩.

直接代入 H，得到 E₊=ε+t、E₋=ε−t。两种奇偶性由对称性标记；能差 2|t| 要由耦合强度决定。t<0 时对称组合较低，t>0 时次序反过来，t=0 时二者偶然简并。奇偶性不同本身并不决定高低。

若 δ≠0，求特征方程：

det(H−EI)=(ε−E)2−δ2−t2=0,Elow/high=ε∓t2+δ2.

此时 P 不再是 H 的对称性，一般本征态会混合两种奇偶性。网页显示本征矢的左右振幅、⟨P⟩和对易子大小。两条局域基只是教学模型，不等同于真实 H₂ 分子完整的电子结构计算。

03 哪些跃迁会被对称性“消掉”？

先看矩阵元，而不是先看峰的高度〔教学扩展〕

跃迁强度的一个关键因子是矩阵元

Mfi=⟨ψf|O|ψi⟩.

在一维反演 P 下，设初态、末态和算符的奇偶性分别为 pi、pf、pO，每个都是 ±1。对积分变量作 x→−x，得到

Mfi=pfpOpiMfi.

若乘积为 −1，只能有 M=0。若乘积为 +1，对称性没有强迫它为零，但积分仍可能因其它结构或额外选择定则而为零。对电偶极近似中的 x 分量，pO=−1，所以相同奇偶性的态之间被禁止；更高多极过程、外场或振动耦合可能改变适用条件。

把正负贡献画出来〔教学扩展〕

为了实际算积分，取无量纲简谐振子的前三个归一化函数：

ϕ0=π−1/4e−x2/2,ϕ1=2xϕ0,ϕ2=2x2−12ϕ0.

它们的奇偶性依次是偶、奇、偶。令初态为 φ₀，末态为 ψf=cosαϕ1+sinαϕ2。α=0 时是纯奇态；α≠0 时是人为设置的奇偶混合态，用于展示选择定则如何失去前提，不声称这是上一个模型外场的定量结果。

利用高斯积分或升降算符，可得

⟨ψf|x|ϕ0⟩=cosα2,⟨ψf|x2|ϕ0⟩=sinα2.

展开：两个非零积分怎样算出来？

用归一化高斯分布的二阶与四阶矩：

1π∫−∞∞x2e−x2dx=12,1π∫−∞∞x4e−x2dx=34.

因此，φ₁与 xφ₀ 的重叠等于 √2×1/2=1/√2；φ₂与 x²φ₀ 的重叠等于 (2×3/4−1/2)/√2=1/√2。其余两项分别为奇函数积分，等于零。末态展开中的 cosα、sinα 再乘上去，就得到面板上方的两条解析式。

网页把被积函数在 x 与 −x 的贡献成对标出，并用 Simpson 积分与解析结果交叉核对。x² 是一个方便观察偶算符的教学例子，可类比讨论某些偶对称响应的空间结构，但这里并未构建真实 Raman 极化率。

还有一个反例值得记住：φ₀ 与 φ₃ 的奇偶性允许电偶极 x 跃迁，但简谐振子中 ⟨φ₃|x|φ₀⟩仍为零，因为 x 只连接相差一个量子的振子态。“未被反演禁止”和“矩阵元非零”是两层判断。

04 五个应用方向：从绪论看到整本书

原章依次预告第二部分的五个应用领域。下面逐一说明它们的问题、群论给出的结构，以及仍然需要输入的物理量。所有可调模型都是本教程自编的预习，不把后续章节的正式推导提前算作第一章内容。

4.1 第7章：有机分子轨道，以及协同反应的对称性

许多原子轨道组合成分子轨道时，直接求解大矩阵容易掩盖结构。按对称性选择线性组合后，不同对称类型不能耦合，久期方程因而可以分块。原章也提到协同反应中的 Woodward–Hoffmann 规则；判断真实反应还要给定反应路径、电子占据和热/光激发条件，本章不把它简化成一句“对称就反应”。

四轨道环演示。 用四个正交局域轨道组成等间距的教学环，只保留相邻耦合。它是代数模型，并非对某一种真实分子的几何、磁性或键长的定量预测：

H=(εt0ttεt00tεtt0tε).

取基向量

s=12(1,1,1,1)T,a=12(1,−1,1,−1)T,u=12(1,0,−1,0)T,v=12(0,1,0,−1)T.

把它们作为 Q 的列，逐项计算得

QTHQ=diag(ε+2t,ε−2t,ε,ε).

由四维问题变成两个一维块与一个二维块。只调 t，会改变能差而保留块结构。若把一条边的耦合改成 t+η，则原四重旋转被破坏，原 Q 基下一般出现非对角项。换基始终合法，但原来的块结构不再受到该对称性保护。动画显示振幅的符号，而非电子在四个原子间作经典跳跃。

4.2 第8章：ABₙ 型无机分子的分子轨道

中心原子 A 周围有 n 个等价配体时，可先在配体轨道上组合出具有确定变换方式的配体群轨道，再与中心原子上对称类型相容的轨道匹配。这比“每个轨道都与每个轨道任意混合”更有组织。

以沿 z 轴对置的两个配体为例。选定一对在反演下恰好互换且无额外相位的配体 σ 轨道 L、R，则组合 (L+R)/√2 为偶，(L−R)/√2 为奇。中心 s 轨道是偶，pz 是奇。保持反演时，s 只可能耦合偶组合，pz 只可能耦合奇组合。轨道的相位约定会改变组合的书写符号，不能脱离变换定义死记“加号就是成键”。

网页配体匹配器可以点选 s 或 pz，显示匹配通道。对称性只是第一道筛选；即使同类，能量相差太大、空间重叠太小，也可能几乎不混合。滑动耦合强度，可以看到“允许”的通道在零耦合时照样没有能量排斥。

4.3 第9章：晶体场与配位场中的内层轨道

自由原子的 d 轨道在球对称单电子模型中构成五维空间。放入理想八面体环境后，这个空间分成一个二维 eg 子空间和一个三维 t₂g 子空间。常用实基为 (dz²,dx²−y²) 与 (dxy,dyz,dzx)。保持 Oh 对称时，各子空间内部不能被任意劈裂；对称性并不单独给出两组间的能差。

网页采用简单八面体排斥模型：轴向轨道更直接朝向六个配体，设 e_g 较高，并把五个能级的加权重心置零。令 Δ=E(eg)−E(t2g)，则

2E(eg)+3E(t2g)=0,E(eg)=35Δ,E(t2g)=−25Δ.

第一式是此处人为选取的能量零点，第二式是结合能差后的代数结果。Δ 的数值、正负与真实化学成键机制仍需相应模型；本页滑块只使用常见的 Δ≥0 八面体示意。它不是完整的多电子项、交换作用、成对能、高低自旋或 Jahn–Teller 理论。

4.4 第10章：分子振动、红外与 Raman 光谱

一个非线性、孤立的 N 原子分子共有 3N 个小位移自由度。整体平移占3个，整体转动占3个，剩下 3N−6 个振动自由度。线性分子的转动只有两个独立方向，所以计数为 3N−5。水是非线性三原子分子，因此有3个正常振动。

对称性可以分类这些振动，并判断它们是否满足某种谱学过程的必要条件。红外电偶极活性看振动是否能改变偶极矩的相应分量；普通非共振 Raman 分析看极化率张量的变换类型。活性不等于强度；定量频率还要用质量与力常数。原章把 F–G 矩阵法作为后续定量计算的入口。

本页的可计算水模型采用三项内部坐标 q=(Δr₁,Δr₂,Δθ)，以平衡结构为展开点，取

V=12kr[(Δr1)2+(Δr2)2]+12kθ(Δθ)2.

这里键长、质量和能量都取教学单位；kθ 与 kr 的原始物理量纲不同，不能比较滑块数值大小来判断现实水分子的“哪种键更硬”。令 B 是内部坐标对笛卡尔位移的一阶导数，M 是对角质量矩阵，则

K=BTdiag(kr,kr,kθ)B,D=M−1/2KM−1/2,Deν=ων2eν.

网页在 yz 平面内构建 6×6 的 D，去掉两条平移与一条面内整体转动的零模，保留全部三个振动；完整三维模型还会多出面外两转动与一平移零模。实际原子位移为 M−1/2eνcos(ωνt)，不能把质量加权本征向量直接当成位移。

对所选 yz 分子平面、z 主轴，模式分解为 2A₁+B₂：两条 A₁ 正常模一般是对称伸缩与弯曲的混合，B₂ 是反对称伸缩。不要把“弯曲”与“对称伸缩”当作同一表示下永不混合的精确标签。本页按频率排序，并显示每条模式的内部坐标成分、对称性和数值频率。改变力常数，对称分类保留而频率移动。给两侧同时换成 D 保持交换对称性，但频率变化；只换一侧则破坏质量交换对称，原来的奇偶分类不再成立。本页振动面板仅比较 H₂O 与 D₂O。

实际水在不同实验轴约定中反对称伸缩可记作 B₁ 或 B₂；须先看坐标定义。NIST 水分子数据可用于核对实际气相频率与其所用标签，本页不拟合这些数值。

4.5 第11章：从分子点群走向晶体空间群

分子点群操作保持某一点不动；晶体还具有平移周期性。把同一原胞重复排开，平移一个晶格常数会把无限晶体映回自身。在有限链上，只有无限周期延拓或周期边界条件才严格具有这条平移对称性，开边界本身会破坏它。

对一维周期势，若 T_aψ(x)=ψ(x+a)，那么平移本征态满足

Taψk=eikaψk,ψk(x)=eikxuk(x),uk(x+a)=uk(x).

周期的是 uk，不是任意 k 的整个 ψk。网页先在一维点阵上显示相邻原胞间的相位变化，再显示有限 N 个同强度散射中心的结构振幅

FN(q)=∑n=0N−1eiqna,IN(q)=|FN(q)|2.

在 q a=2πm 时，各项同相，强度为 N²；其它 q 处相位可能相消。增加 N，会看到主峰变窄。此处是单散射、等振幅、单位原胞的有限一维干涉模型，未包含原子形状因子、温度因子、多重散射或三维晶体结构精修。它只是把原章提到的晶体学应用变成一个可以试验的入口。

原章给出的阅读路线

第一部分第1–6章讲基本原理，论证层层相接，适合顺序阅读：绪论 → 群的定义与定理 → 分子对称性与对称群 → 群的表示 → 群论与量子力学 → 对称适应线性组合。

第二部分第7–11章分别处理有机分子轨道、无机分子轨道、配位场、分子振动与晶体学对称性。作者尽量让这些应用章节彼此独立，但它们都依赖第一部分。学完基础后，可以按自己的研究方向选择进入某个应用，不必为了看振动先逐章掌握所有有机反应内容。

附录把部分专门讨论、矩阵知识、常用表格和延伸阅读集中起来，避免打断主线。表格适合查证与计算，不能代替“这个操作作用在哪个空间、采用哪套坐标与基”的理解。

给凝聚态读者的桥梁〔教学扩展〕

可以把本书的几个对象逐一翻译到熟悉的场景：分子轨道对应局域轨道和紧束缚基；分子振动对应动力学矩阵和声子；配位场中的轨道分类对应局域晶场与轨道劈裂；分子平移之外的晶体对称性，最终连接到能带、空间群和 k 点小群。

但不要把分子点群结论直接套给整个固体。在一般 k 点，需要满足 Rk=k+G 才属于相应小余群；非平移对称操作可能带来额外相位。含自旋轨道耦合的自旋1/2问题还要引入双值表示；时间反演是反幺正对称性，不能只用本页的实矩阵交换来代替。这些都是以后扩展的方向，本章只把路线标出来。

06 自测：先预测，再拖动滑块

  1. 左右环境完全相同，把双轨道耦合 t 从 −1 调到 −2，奇偶性会不会改变？为什么能差改变？
  2. δ=0、t=0 时，两个态不同奇偶却等能。这是否违反对称性？
  3. 奇末态、偶初态之间，偶算符的矩阵元为什么为零？加上偶末态分量后呢？
  4. “对称性允许”的跃迁能否仍然没有强度？举本章的一个例子。
  5. 把水的两个 H 同时换成 D，为什么可以保持对称分类却改变频率？
  6. Oh 给出 d 轨道的 2+3 分组，能否仅靠这条信息确定 Δ？
  7. 在晶格相位图中，k≠0 时 ψ 在相邻原胞是否必须相等？

展开参考思路

  1. 对称组合不变；能差 2|t| 由动力学参数改变。
  2. 不违反；对称性没有禁止不同一维类型偶然等能。简并时也可选择奇偶基。
  3. 被积函数为奇函数，正负贡献严格相消；混合后纯奇偶性的前提不再成立。
  4. 可以，例如把配体的允许通道耦合设成零，或简谐振子 φ₀→φ₃ 的 x 矩阵元。
  5. 相同方式改变两侧质量仍与交换操作相容，但动力学矩阵包含质量。
  6. 不能，需电子结构、相互作用模型或实验；能量重心零点也是人为约定。
  7. 不必须，它可以积累 e^{ika} 相位；周期的是 u_k。
