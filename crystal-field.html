01 / THE PHYSICAL PICTURE

先看方向，再谈能量

孤立离子的中心势只依赖距离 r，五个 d 轨道属于角动量 l = 2 的同一个五维空间。忽略自旋–轨道耦合时，它们简并。配体的非球形电势破坏连续旋转对称性，轨道对不同方向电荷的响应不再相同。

最简单的晶体场模型把配体当作点电荷或点偶极子。负配体对金属 d 电子产生排斥；电子密度越朝向配体，通常能量越高。这个直觉解释典型 σ 配位场，但不能替代完整积分，更不能单靠“叶瓣数”预测所有能级。

三个问题，三种答案

形状告诉你轨道朝哪里；群论告诉你哪些态必须一起简并；哈密顿量及其参数才告诉你具体分裂多少。对称性通常不能单独决定能级高低。

晶体场 CFT

电荷分布产生的静电势。适合建立局域能级、简并与磁性的第一层图像。对于自由离子，先有电子间排斥和原子项；晶体场再将这些项分裂。

配位场 LFT

把金属–配体共价杂化、σ / π 成键也纳入。许多真实材料的“晶体场参数”其实是有效配位场参数。CO、CN⁻ 的强场尤其不能只用配体净电荷解释。

02 / A MAP OF SYMMETRIES

“有多少种”，先说明按什么分类

没有一个普适的“晶体场总数”。无限多种配体距离、角度与化学组成都可以产生不同的场。如果按三维周期晶体允许的点对称性分类，有 32 个晶体学点群；它们归属 7 个晶系。空间群则有 230 种，但空间群数不是局域晶体场的种类数。[1]

晶体里应当使用目标离子所在位置的位点群；它可能比整个晶体的点群低得多。只保留第一配位壳层时，还可能得到更高的“近似局域对称性”。孤立分子可有非晶体学点群，如 D5h；线型配合物理想化可用 D∞h，不在这 32 个之内。

04 / WHY DEGENERACY SURVIVES
从五维表示，拆出 2 + 3
把五个实 d 轨道当作一组基函数。对每个群操作 R，计算它如何线性组合这五个函数，得到 D⁽ᵈ⁾(R)；矩阵迹 χ⁽ᵈ⁾(R) 就是特征标。若场具有群 G 的对称性，则 [H,D(R)] = 0。
Schur 引理的物理含义
一个不可约表示中的等价方向不能被对称哈密顿量区别对待，所以同一个不可约块内部保持简并。但是同一种不可约表示出现多次时，不同副本之间可以混合；这正是 A₁ + 2E 中“两份 E”的含义。

05 / CALCULATE, DON'T MEMORIZE
能级到底怎样算？
路线一：点电荷晶体场，从积分出发
令 e 为正的元电荷，配体 j 的实际电荷为 Q_j，位置为 R_j。电子势能为下式。负配体 Q_j<0 对电子给出正排斥；不要把静电势 φ 与电子势能 −eφ 的符号混淆。
V(r) = − e / (4πε₀) Σ_j Q_j / |R_j − r|
H_mm′ = ∫ R*nl(r) Y*lm(Ω) V(r) Rnl(r) Ylm′(Ω) r² dr dΩ
  1. 读取局域配体坐标和有效电荷，选择坐标轴及轨道基。
  2. 给定径向波函数，做数值积分，或把势展开成球谐函数。
  3. 构造厄米矩阵 H，减去 Tr(H)/5 只研究分裂，保留原迹可研究绝对平均位移。
  4. 对角化求本征值与本征矢；检查简并、收敛与对称性。
H_CF = Σkq B_kq C_q⁽ᵏ⁾　　（在固定 d 壳层内，k = 0, 2, 4）
球谐矩阵元满足三角规则 k≤2l，且同宇称壳层只保留偶 k。k=0 仅整体平移；立方对称性还会禁掉 k=2。在配体都位于电子主要分布区域之外的展开中，k 阶系数带有 ⟨rᵏ⟩/Rᵏ⁺¹；因此常见立方 d 分裂的点电荷尺度为 R⁻⁵。若给出 B_kq，必须说明是球谐、Wybourne 还是 Stevens 约定，不能直接混用数值。
补充代码：真正对点电荷势做角向积分
另附 point_charge.py，用 Gauss–Legendre × 等距方位角求积，在归一化实 d 球谐基中积分点电荷势。示例把径向分布近似为 r=0.25 的薄球壳，配体半径 R=1，六个配体均取 Q=−1；输出为无量纲库仑能，不是某材料的 eV 参数。
# 核心求积；Y[n,m] 为归一化球谐基，w[n] 为立体角权重
V = -sum(Q[j] / norm(R[j] - r*u) for j in ligands)
H = np.einsum('ni,n,nj->ij', Y, w*V, Y)
H -= np.trace(H)/5 * np.eye(5)
E, U = np.linalg.eigh(H)

06 / COMPETING ENERGY SCALES
分裂之后，电子如何选择？
先由氧化态求 d 电子数：常用离子计数中 dⁿ≈族序数−氧化数。Fe²⁺ 是 d⁶，Mn³⁺ 是 d⁴，Cu²⁺ 是 d⁹；强共价体系的真实 d 占据不一定等于这个形式计数。
电子既想占低能轨道，也受泡利原理和 Hund 交换影响。常用入门模型把同轨道成对代价压缩成 P：E=Σ_i n_i ε_i + N_pair P。比较方案时必须用同一个 P 定义和同一个能量零点。
实验 D · 八面体填充与自旋竞争
枚举五轨道 0/1/2 占据，最小化上述简化能量；等能时选未成对数最多的方案，并按 Hund 规则将未成对电子平行排列。它不计算完整原子多重态、交换参数或中间自旋稳定区。Δ=P 处显示的是并列候选之一。
CFSE = (−0.4 n_t₂g + 0.6 n_eg) Δₒ
μ_spin-only ≈ √[n_unpaired(n_unpaired+2)] μ_B
什么因素让 Δ 变大？
同类配位环境中，更短的金属–配体距离通常增强分裂；较高金属氧化态常使场增强，4d / 5d 与 3d 的径向延展差异也很重要。配体效应常以经验光谱化学序列表达，例如 I⁻ < Br⁻ < Cl⁻ < F⁻ < H₂O < NH₃ < CN⁻ < CO（由弱到强，概略顺序）。这不是普适常数表，金属、价态与成键方式都会影响它。
在近似八面体中，π 给体配体的占据 p 轨道可把金属主导 t₂g 反键态推高，减小 Δ；CO 等 π 受体的空 π* 轨道可使金属主导 t₂g 成键态降低，扩大 Δ。这也解释了为什么纯静电模型不足以解释完整的光谱化学序列。[4]
以 d⁶ 为例，真正比较一次
高自旋 t₂g⁴e_g²，CFSE=−0.4Δₒ，有 1 对、4 个未成对电子、S=2；低自旋 t₂g⁶，CFSE=−2.4Δₒ，有 3 对、S=0。因此 E_LS−E_HS=−2Δₒ+2P，这个模型在 Δₒ=P 交叉。注意 CFSE 本身不包含配对能。
八面体 d⁴、d⁵、d⁶、d⁷ 具有常见的高低自旋竞争；d³、d⁸ 在理想八面体中没有这种通常意义的两种填充。四面体场通常较弱而多为高自旋，但“所有四面体必然高自旋”不是定理。平面四方 d⁸ 如 [Ni(CN)₄]²⁻ 常为低自旋抗磁；四面体 [NiCl₄]²⁻ 则有未成对电子。
4d / 5d 轨道通常更延展，配位场与 SOC 可更强；稀土 4f 轨道较受屏蔽，通常先在强 SOC 下形成 J 多重态，再讨论晶体场。这两类材料不能照搬 3d 的简单填充图。


07 / WHEN SYMMETRY BREAKS ITSELF
Jahn–Teller：降低对称性，反而更稳定
规范名称为 Jahn–Teller（姜–泰勒）效应。对非线性体系，空间轨道简并的电子态通常可通过与畸变耦合降低能量；讨论平衡结构时重点检查电子基态。关键是多电子态的轨道简并，而不是“有未成对电子”，也不是只有自旋简并。[6]
为什么 d⁹ 铜离子常出现伸长？
理想 Oₕ 中 Cu²⁺ 为 t₂g⁶e_g³：两个 e_g 轨道中一个双占、另一个单占。沿 z 伸长通常降低 d_z² 相对能量，让两个电子占较低轨道，只让一个电子留在较高的 d_x²−y²，产生净能量收益。轨道能之和虽不变，但有电子占据加权之后，总电子能可以降低。弹性能最终阻止无限伸长。
实验 E · 电子能收益，对抗晶格弹性
无量纲一维 E⊗e 模型截面，K=1。Q>0 示意轴向伸长，Q<0 示意压缩。忽略高阶项，两个方向等能；因此该图不能证明所有材料都优先伸长。键长变化为示意缩放。
H_JT = g(Qθ τ_z + Qε τ_x) + ½K(Qθ²+Qε²)I
E±(ρ) = ½Kρ² ± gρ，ρ=√(Qθ²+Qε²)
ρ₀ = g/K　　E_JT = g²/(2K)
τ 是作用于简并电子双态的泡利矩阵，不是真实自旋。对上面的 d⁹ 直觉，e_g³ 的两个分裂轨道能量为 ±gQ，最低占据电子能相对收益为 −g|Q|。完整二维线性模型的下势能面具有环形谷底；高阶各向异性可将其变为离散极小值，决定伸长或压缩等细节。

群论如何筛选可耦合振动？
线性耦合矩阵元要求振动表示 Γ_Q 包含在电子表示的对称平方 [Γ_el⊗Γ_el]_sym 中；去掉只让整体移动的全对称分量，剩余模式才可能解除简并。例如 Oₕ 中 [E_g⊗E_g]_sym=A₁g⊕E_g，所以 e_g 型 Qθ、Qε 模式可线性耦合 E_g 电子双态。对 T₂g，有对称平方 A₁g⊕E_g⊕T₂g，存在多种候选模式。
静态、动态与协同
静态 JT：局域畸变在观测时间内固定。动态 JT：在等价极小值间跃迁或量子隧穿，时间平均结构可能看起来高对称。协同 JT：相邻多面体通过晶格相互耦合，形成有序畸变；LaMnO₃ 的 Mn³⁺ 是典型例子。[7]
没有简并，也能畸变吗？
可以。赝 JT 效应可由近邻非简并电子态的振动混合产生；应变、尺寸失配、极性位移和八面体转动也能畸变。看到长短键不等，不足以单独证明一阶 JT；Ti⁴⁺ d⁰ 也不能因此被排除出所有电子驱动畸变。
纯粹的 Kramers 双重简并来自时间反演对称性。非磁性结构畸变不能解除一个孤立 Kramers 双态的保护简并，因此“有双重态”本身不能作为普通 JT 活性的证据；强 SOC 时须重新分析自旋–轨道纠缠多重态的振电耦合。


08 / READING REAL MATERIALS
把教程带回材料
01
SrTiO₃：空轨道也有分裂
室温立方相的 Ti⁴⁺ 形式 d⁰，TiO₆ 的理想 Oₕ 场把空 d 态分成 t₂g、e_g。没有 d 电子并不等于没有晶体场；它只意味着不出现普通的占据 d–d 吸收。真实导带还受 Ti–O 杂化与能带色散影响。低温结构发生变化，不能把室温 Oₕ 标签原样套用到所有温度。[2]
02
LaMnO₃：强 JT 与轨道有序
Mn³⁺ 高自旋 d⁴，t₂g³e_g¹，存在 E_g 型轨道简并的强 JT 倾向。实际正交晶体中 MnO₆ 畸变与转动并存，多个局域畸变协同排列。这里 Oₕ 是用来定义轨道的高对称参考，实际低对称基态中的简并已解除。[7]
03
Fe(CO)₅：几何对称，不等于静电足够
气相分子近似 D₃h，d 轨道分成 A₁′、E′、E″。CO 的 σ 给电子与 π 回馈都重要，因此网页的 σ-only 能级次序不能当作它的定量电子结构。固态分子的局域形状近似 D₃h，但晶体学位点为 C₂，更说明要分清“分子形状”和“精确位点群”。[3]
颜色和磁性：重要但不能过度解读
有反演中心时，纯局域 d–d 电偶极跃迁同为 g→g，受 Laporte 规则禁戒；振动耦合、p–d 混合可赋予弱强度。自旋选择规则近似 ΔS=0，SOC 会放宽它。电荷转移跃迁往往更强，因此不能仅凭颜色直接读出 Δ 或 d 电子数。
自旋仅磁矩公式适合轨道角动量大体淬灭的情况。Co²⁺、重元素和强 SOC 材料常有显著轨道贡献；温度、交换关联与磁有序也影响测得的磁化率。
f 电子：同样的对称性，更换能量层级
对常见三价稀土 4f 离子，电子间库仑作用与 SOC 往往先确定基态 J，再在 (2J+1) 维空间中使用 Stevens 算符 H_CF=Σ B_k^q O_k^q(J)。f 壳层可涉及 k=2、4、6，非所有 q 都由对称性允许。奇电子数离子在保持时间反演时留下 Kramers 双态；偶电子数离子可有非 Kramers 双态或单态。系数包含径向平均与算符约定，不能把 d 轨道 Dq 直接搬到这里。
面对一个新材料，按这条路线走
CIF / 实验结构 → 目标位点及邻居 → 精确与近似点群 → 价态与 dⁿ / fⁿ → 能量尺度（场、库仑、SOC）→ 对称允许的哈密顿量 → 拟合 / 从头计算 → 用光谱、磁性与结构交叉验证。


09 / CHECK YOUR UNDERSTANDING
四个问题，检验是否真正理解
① 为什么 d³ 有未成对电子，却通常没有一阶 JT？
八面体基态 t₂g³ 按 Hund 规则占据，整体多电子基态为轨道单态 ⁴A₂g。自旋多重度 4 不意味着轨道简并，因此不触发通常的一阶 JT；其他机制仍能导致畸变。
② Oₕ 的 E_g 和 D₄h 的 E_g 对应同一对轨道吗？
不是。前者是 (z²,x²−y²)，后者是 (xz,yz)。群不同，表示标签的含义就不同。
③ 看到两个能级差，能否由点群计算出 eV？
不能。点群只约束矩阵结构、简并及允许混合。具体能差需要电势、径向积分、杂化参数或实验数据。
计算练习 · Δₒ=2 eV 时，d³ 和高自旋 d⁴ 的 CFSE？
d³：t₂g³，CFSE=−1.2Δₒ=−2.4 eV，3 个未成对电子。高自旋 d⁴：t₂g³e_g¹，CFSE=(−1.2+0.6)Δₒ=−1.2 eV，4 个未成对电子。这些是给定结构下相对轨道重心的稳定化能，不能直接当成两种不同材料之间的总能差。
④ 为什么 d¹⁰ 材料可以畸变，却不是常见一阶 JT？
填满壳层的基态轨道不简并，单纯重新分裂满壳层轨道不带来一阶占据能收益。尺寸失配、外应变、赝 JT 等机制仍可引起结构变化。
建议的学习顺序
先用实验 A、B 建立方向感；再手算一次 O 群约化；接着用实验 D 比较 d⁴ / d⁵ / d⁶ / d⁷；最后把实验 E 与 JT 速查表相互验证。更深入时依次读多电子项、Tanabe–Sugano 图、SOC、振电耦合与实际能带中的 Wannier 局域模型。
