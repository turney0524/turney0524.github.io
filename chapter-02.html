学习目标

学会把初态分解为能量本征态，理解六种典型势能模型，并区分束缚态、散射态和波包。

2.1

CONCEPT / DERIVATION / EXPLORATION

定态：把时间与空间分开

不动的是概率分布，不是波函数。

第一章教我们“有了 Ψ，可以计算什么”。现在反过来问：给定一个势能 V，怎样得到 Ψ？当 V 不显含时间时，先寻找乘积形式 Ψ(x,t)=ψ(x)ϕ(t)。代入薛定谔方程，再除以 ψϕ，左侧只依赖 t，右侧只依赖 x；两侧只能等于同一个常数 E。

读这个式子：第一式是定态方程；第二式把该能量对应的时间因子补回去。E 的单位是能量。

对于这个分离变量解，时间因子在模平方中抵消，所以位置密度和不显含时间算符的期待值不变。更强的结论是能量方差为零：它是能量确定的态。一般初态却是许多个定态的叠加，不必具有静止的密度。

读这个式子：有连续谱时，相应部分需改用积分；不能把所有势能问题都写成纯离散求和。

一步一步算

两个定态，如何产生运动？

若初态为 (ψ₁+ψ₂)/√2，且空间本征函数取实数，密度为 [ψ₁²+ψ₂²+2ψ₁ψ₂ cos((E₂−E₁)t/ℏ)]/2。各个定态本身的密度不动，相对相位产生的交叉项却在变。

2.2

CONCEPT / DERIVATION / EXPLORATION

无限深方势阱

能量不是被“规定”为离散的，是被边界筛选出来的。

取 V=0（0<x<a），区间外势能无限大。内部微分方程给出 A sin(kx)+B cos(kx)。由 ψ(0)=0 得 B=0，再由 ψ(a)=0 得 ka=nπ。n=0 只给零函数，负 n 也不产生独立的新态，因此 n=1,2,…。

读这个式子：阱宽翻倍，所有能级降为原来的四分之一；质量越大，能级越密。

这些函数正交归一，且在相应的平方可积空间中构成完备基。把它们看成一套“量子乐器的纯音”：复杂的初态可由纯音叠加，但各纯音的频率由能量决定。第 n 态在阱内有 n−1 个节点。

一步一步算

从一个抛物线形初态开始

若 Ψ(x,0)=Ax(a−x)，归一化给 A=√(30/a⁵)。投影到正弦基后，偶数 n 的系数为零，奇数 n 的系数为 8√15/(n³π³)。将每个系数乘上各自的时间相位，就得到了后续演化。奇偶筛选来自初态关于阱中心的对称性。

基态为什么不能有零动能？
若 ψ 在阱内是非零常数，就无法同时满足两端为零与连续性。最低允许空间起伏已经需要非零动能，这也与位置受限时的动量不确定性一致。
2.3

CONCEPT / DERIVATION / EXPLORATION

谐振子

最低能量没有归零，阶梯也不能无限下降。

任何光滑势能在稳定极小值附近都可展开为 V(x)≈V(x₀)+mω²(x−x₀)²/2。因此谐振子是小振动问题的共同语言。略去能量常数并平移原点后，H=p²/(2m)+mω²x²/2。

读这个式子：a 和 a† 是降阶、升阶算符；[a,a†]=1。

把能量本征态反复降阶不可能降到负无穷，因为动能与势能均非负。最低态必须满足 aψ₀=0。解这个一阶方程得到高斯，再反复升阶得到整个能谱。

读这个式子：这里 n 从 0 开始，与无限深势阱不同。等间隔能级是谐振子特性，不是所有势能的普遍性质。

读这个式子：解析法令波函数等于高斯乘幂级数；要求级数截断以保证可归一化，得到同一组能级和 Hermite 多项式。

经典禁区不等于量子密度必为零

在 E<V 的区域，波函数仍可有指数尾部。它不是粒子沿着某条负动能轨迹运动；不能将经典轨迹概念直接套到波函数上。

2.4

CONCEPT / DERIVATION / EXPLORATION

自由粒子

平面波有确定动量，真正局域的粒子需要波包。

取 V=0，空间解为 eⁱᵏˣ 与 e⁻ⁱᵏˣ，E=ℏ²k²/(2m)。在整个实轴上，一个平面波不能归一化，它是展开一般态的广义基函数。局域态需要连续波数的叠加。

读这个式子：此处 φ 按波数 k 归一化；若使用动量 p 的概率幅，需要相应的变量变换因子。

相速度 ω/k=ℏk/(2m)，不是自由粒子的平均速度。窄波数带波包的包络以群速度 dω/dk=ℏk/m 移动。色散关系不是直线，因此不同波数分量的相位逐渐展开，波包会变宽。

群速度与相速度之差说明什么？

2.5

CONCEPT / DERIVATION / EXPLORATION

δ 函数势

一个无限窄的势，也能留下有限的物理效果。

Dirac δ 不是普通的有限高度函数，它通过积分取样定义：∫δ(x−a)f(x)dx=f(a)。取吸引势 V=−αδ(x)，α>0。原点两侧势为零，束缚态只能选向无穷远衰减的指数。

读这个式子：第二个条件来自把薛定谔方程跨过原点积分。δ 势处导数不连续，不能套用有限连续势的全部接续条件。

读这个式子：任意 α>0 恰有一个束缚态；越强的吸引势，态越窄、能量越低。

2.6

CONCEPT / DERIVATION / EXPLORATION

有限深方势阱

边界外的尾巴，改变了边界内的能量。

取阱内 V=−V₀（|x|<a），外部 V=0。束缚态满足 −V₀<E<0：阱内振荡，阱外衰减。由偶、奇对称性分别匹配波函数和一阶导数，问题转成寻找超越方程的根。

读这个式子：偶态使用余弦；奇态的条件为 −z cot z=√(z₀²−z²)。只接受 0<z<z₀ 的根。

互动 06

逐渐加深一个有限阱

先预测，再操作新束缚态会连续从最低处长出，还是从阱顶附近出现？

匹配条件的数值二分求根；ℏ=m=a=1，V₀=z₀²/2。横线为束缚能，不是波函数。超出可用数目时选中最后一态；纵轴随阱深调整。 播放比较的是不同参数的结果，不代表这些状态之间的实际时间演化。

浅阱中的最低偶态仍可存在，但奇态需要足够深的阱。加深势阱或增大阱宽，会容纳更多束缚态。对于 E>0，波不再在两侧衰减，而成为散射态；某些能量可发生完全透射的共振。

边界条件是贯穿本章的方法

不是先猜一串允许能量，再配上波函数，而是先写各区域的通解，剔除不合要求的增长项，再由匹配条件筛出允许能量。

RECALL & PRACTICE

合上这一章之前

先用自己的话回答，再展开检查。

阱宽变为 2a，基态能量怎样变？
变成原来的 1/4，因为 E₁∝a⁻²。
单一定态一定处处没有概率流吗？
不一定。密度不变只要求概率流的散度为零。在一维实势、实轴上适当衰减的非简并束缚态可取实空间波函数，概率流为零；环上的行波定态却可以有稳恒流。
谐振子基态的位置与动量宽度？
σₓ=√(ℏ/(2mω))，σₚ=√(mℏω/2)，乘积为 ℏ/2。
