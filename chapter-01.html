1.1

THE EQUATION

薛定谔方程

从牛顿的轨迹，到量子的状态。

经典力学的主角是一条轨迹。量子力学的主角，是一个随时间演化的波函数。

设一个质量为 m 的粒子只能沿 x 轴运动。在经典力学中，知道初始位置与速度，再用牛顿第二定律，就能求出它以后每一刻的位置。对于来自势能的力，有 F = −∂V/∂x。从轨迹还能求出速度、动量和能量。

量子力学更换了要计算的对象：我们求复函数 Ψ(x,t)。它由含时薛定谔方程决定：

iℏ ∂Ψ/∂t时间如何变化
−ℏ²/(2m) ∂²Ψ/∂x²动能所对应的操作
VΨ势能的作用

这里 i² = −1，ℏ = h/(2π)，约为 1.055 × 10⁻³⁴ J·s。给定初始波函数 Ψ(x,0)、势能与相容的边界条件，方程决定以后的 Ψ(x,t)。正如牛顿方程是经典动力学的基本规律，这个方程是本课程量子动力学的出发点。

最先记住的一次转换

“求出波函数”还不等于“算出粒子的轨迹”。我们需要另一条规则，把波函数与实际测量联系起来。

为什么会有复数？

把波函数写成 Ψ = u + iv，实部 u 和虚部 v 都是实函数。共轭 Ψ* = u − iv，因此 |Ψ|² = Ψ*Ψ = u² + v²。实部可以为负，模平方始终非负。复数的相位会影响叠加与动量，不能把虚部删掉。

停一下：波函数演化是确定的，测量为什么还会随机？
薛定谔方程确定的是整个波函数。由波函数得到的是各测量结果的概率分布，不是预先指定的一次结果。确定的分布与随机的样本可以同时存在。

THE INTERPRETATION

波函数的统计诠释

曲线下面的面积，才是实验中的概率。

波函数提供概率幅；模平方提供位置的概率密度。

Born 的统计诠释把数学对象接到了实验上。在时刻 t，位置落在 a 与 b 之间的概率为：

如果区间非常小，概率约为 ρ(x,t) dx。曲线的高度叫概率密度，曲线下的面积才叫概率。一维中，ρ 的单位是长度的倒数，Ψ 的单位是长度的 −1/2 次方。密度的数值可以大于 1，区间概率却不能大于 1。

同一制备，一次一个结果

想象准备许多状态完全相同的粒子，对每一个只测一次位置。得到的点并不会整齐地排成曲线；次数增加后，相对频率逐渐显出 |Ψ|² 的轮廓。量子理论在这里预测的是同态系综的统计规律。

互动 02

把密度变成一块面积

拖动区间的左右端点。阴影面积是这个区间的位置概率，和曲线某一点的高度不是同一个量。

每次测量均重新制备标准高斯态 σₓ = 1、⟨x⟩ = 0。蓝柱是样本密度，图外样本仍计入总数；跨过端点时自动将两端排序。改变区间不会改变制备的态。

测量之前在哪里？测量以后又怎样？

书中介绍了现实主义、正统诠释与不可知的立场，借此强调：同一个概率公式，并不自动给出唯一的“测量前故事”。本章先采用正统框架：测量前不为一般态赋予一个确定位置，理想位置测量使状态局域到测量结果附近。

如果马上进行第二次理想重复测量，应该再次得到相同结果。但把同一个粒子连续测许多次，不等于从原来的 |Ψ|² 独立采样，因为第一次测量已经改变了状态。之后的自由演化又会使局域波包扩散。

两类过程，先分清楚

在教科书框架中，未测量时的连续演化遵循薛定谔方程；测量时采用状态更新规则。精确到一点的“尖峰”是数学理想化，实际测量只有有限分辨率。这里的采样程序没有模拟坍塌。

连续分布中，单点概率是零，为什么还能测到一个位置？
对于普通连续密度，零宽区间的面积为零；这不妨碍每次结果落在某个位置。实验报告的“某个位置”实际对应仪器有限分辨率的一段区间。
1.3

THE LANGUAGE OF CHANCE

概率的语言

平均值、密度与分散，分别告诉我们什么。

概率告诉我们会得到什么；统计量把整个分布浓缩成几个有意义的数。

1.3.1 分立变量：先从一屋子人的年龄开始

原书给出 14 个人的年龄分布：14、15 岁各 1 人，16 岁 3 人，22、24 岁各 2 人，25 岁 5 人。随机等概率选一个人，年龄 j 的概率就是 P(j) = N(j)/14。

1 人14 岁
1 人15 岁
3 人16 岁
2 人22 岁
2 人24 岁
5 人25 岁

最常见的年龄是 25 岁，叫众数。中间两人是 22 和 24 岁，通常取中位数 23 岁。平均年龄却是 21 岁。没有任何人恰好 21 岁，也不妨碍它成为平均值。

对于任意函数 f，把每一种取值的 f(j) 按其概率加权求和，就得到 ⟨f(j)⟩。例如平方的平均 ⟨j²⟩，一般不等于平均的平方 ⟨j⟩²。

分布“有多宽”？

如果只平均偏差 j − ⟨j⟩，正负总会抵消为零。于是先平方，再求平均，得到方差；开平方后得到标准差。标准差与原变量同单位。

把方差展开，只需要三步

  1. 设 μ = ⟨j⟩，展开 (j − μ)² = j² − 2μj + μ²。
  2. 逐项平均，μ 是常数：⟨j²⟩ − 2μ⟨j⟩ + μ²。
  3. 代入 ⟨j⟩ = μ，剩下 ⟨j²⟩ − μ²。

1.3.2 连续变量：把求和换成积分

年龄精确到无限多位时，不再适合逐个值计数。我们改用密度 ρ(x)，用积分累积区间概率。相应的规则是：

要回答的问题连续分布的计算
所有结果的总概率∫ ρ(x) dx = 1
位置的期待值⟨x⟩ = ∫ xρ(x) dx
某个函数的平均⟨f(x)⟩ = ∫ f(x)ρ(x) dx
位置分布的宽度σₓ² = ⟨x²⟩ − ⟨x⟩²

表中的积分均取整个允许的取值区间。

NORMALIZATION

归一化

总概率为一，而且应当一直为一。

粒子必须在某处被找到，所以整个空间的概率总和必须等于 1。

薛定谔方程是线性的：若 Ψ 是一个解，乘上常数 A 仍是解。对于 Ψ = Af，可以通过选择 |A|，将原本的相对权重校准为总概率 1：

这里要求积分有限且非零。零函数或平方积分发散的函数，不能用常数变成一个整个实轴上的归一化单粒子态。无限延伸的平面波仍是有用的广义态，但不是一个已经归一化的位置分布。归一化只确定 A 的模，整体常相位可以自由选择。

例题 / 从面积反推振幅

分段三角形波函数

考虑 0 < a < b。波函数从 x = 0 处的零线性上升到 x = a 处的 A，再线性下降，到 x = b 处为零，其他地方为零。即左段 Ψ = Ax/a，右段 Ψ = A(b−x)/(b−a)。

注意归一化积的是波函数的平方，不是三角形本身的面积。两段积分分别是 |A|²a/3 与 |A|²(b−a)/3，所以：

进一步可得 ⟨x⟩ = (2a+b)/4。它通常不等于概率密度最高处 a：峰在哪里和平均在哪里，是不同问题。

只在初始时刻归一化，后来会不会失效？

不能为了保持归一化，随手把乘子改成 A(t)；时间导数会多出一项，它通常不再满足原方程。幸运的是，实势能和适当边界条件下，薛定谔演化自动保持总概率。

概率守恒的推导

  1. 从 ρ = Ψ*Ψ 开始，用乘积求导：∂ₜρ = Ψ*∂ₜΨ + Ψ∂ₜΨ*。
  2. 将薛定谔方程及其共轭代入。势能为实数时，两项势能贡献正好相消。
  3. 剩余的二阶导数可以合成一个总空间导数，于是得到连续性方程。

J 叫概率流。在一维中，J 的单位为时间的倒数，表示每单位时间经过某点的净概率。

整个实轴上，如果两端没有净概率流出，积分的时间导数为零，归一化就保持不变。在处理积分分部时，需要波函数及相关边界项足够良好，不能只说“函数趋零”就一概忽略所有导数项。

延伸思考：如果势能含有负的虚部呢？
若 V = V₀ − iΓ，Γ 为正常数，则连续性方程多出一个损失项 −2Γρ/ℏ，总概率按 exp(−2Γt/ℏ) 衰减。有效寿命为 ℏ/(2Γ)。这是原书补充题 1.15 的思路：概率守恒推导中的“实势能”前提已经改变。

动量与算符

看不见的相位，留下可测量的后果。

位置的统计由模平方直接给出；动量还需要知道波函数如何随位置改变。

Ehrenfest 定理：经典规律留下的桥

平均位置与平均动量满足类似经典动力学的关系。但一般 ⟨V′(x)⟩ 不等于 V′(⟨x⟩)，所以不能据此宣称平均位置总是严格沿经典轨迹运动。

如果把势能整体加一个常数 Vc，会发生什么？
波函数多出位置无关的时间相位 exp(−iVct/ℏ)。位置与动量等固定算符的统计不变；总能量的测量值则整体增加 Vc。能量零点改变，不能说“所有物理量的期待值都不变”。

UNCERTAINTY

不确定原理

位置与波长之间，有一个无法逃避的取舍。

短促的波包能指出位置，却难以只拥有一个波长。

想象抖动一根绳子。连续而长的规则波列，波长很明确，却很难说“波恰好在哪里”；一个短促的孤立波峰，位置集中，却不再有唯一清晰的波长。傅里叶分析把这个取舍变成数学：越局域的波，需要越宽的一组波数来叠加。

取 A = √λ；偶对称给出 ⟨x⟩ = 0。由 ∫₀∞x²e⁻ᵃˣdx = 2/a³，得到 ⟨x²⟩ = 1/(2λ²)，σₓ = 1/(√2λ)。落在均值 ± 一个标准差之外的概率是 exp(−√2) ≈ 0.2431。
练习 2：高斯初态 s = 0.5、k₀ = 2，在 ℏ = m = 1 时，t = 1 的位置均值与宽度是多少？
⟨x⟩ = 2，σₓ = √5/2 ≈ 1.1180，σₚ = 1，故乘积为 1.1180，大于 0.5。当前演化面板固定 k₀ = 1；如需验证 k₀ = 2，可用配套交互实验室。
练习 3：平均动量为零，动能是否一定为零？
不是。中心波数 k₀ = 0 的高斯有 ⟨p⟩ = 0，但 ⟨p²⟩ = ℏ²/(4s²)，平均动能为 ℏ²/(8ms²) > 0。相反方向的动量可以互相抵消，平方以后却不能。
